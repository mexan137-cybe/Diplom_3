# Проект автоматизации тестирования UI для Stellar Burgers

Данный проект представляет собой фреймворк для автоматизированного тестирования веб-интерфейса и API тренажёра **Stellar Burgers**. Тесты написаны на языке **Python** с использованием библиотек **Pytest** и **Selenium WebDriver**, а также интегрированы с **Allure** для генерации детальных отчётов.

## 🚀 Архитектура и технологии
* **Python 3.9+** — основной язык разработки.
* **Pytest** — фреймворк для организации и запуска тестов.
* **Selenium WebDriver** — инструмент для автоматизации действий в браузере.
* **Page Object Model (POM)** — паттерн проектирования, разделяющий логику страниц и тело тестов.
* **Requests** — библиотека для быстрой подготовки тестовых данных (создание юзеров, заказов) через API.
* **Faker** — генерация случайных данных для регистрации пользователей.
* **Allure Framework** — визуализация результатов тестирования.

## 💻 Установка и запуск проекта

### 1. Клонирование репозитория и подготовка окружения
```bash
# Клонируйте проект
git clone <ссылка_на_ваш_репозиторий>
cd <имя_папки_проекта>

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Для macOS/Linux
# .venv\Scripts\activate   # Для Windows
```

### 2. Установка зависимостей
Проект содержит оптимизированный список только ключевых библиотек:
```bash
pip install -r requirements.txt
```

### 3. Запуск тестов
Вы можете запускать как все тесты разом, так и точечно конкретные сценарии:
```bash
# Запуск всех тестов проекта
pytest -v

# Запуск тестов из конкретного файла со сбором данных для Allure
pytest -v tests/test_feed.py --alluredir=allure-results

# Точечный запуск одного теста по его названию
pytest -v tests/test_feed.py -k "test_user_order_appears_in_feed" --alluredir=allure-results
```

## 📊 Генерация Allure отчётов

Для визуализации результатов тестов выполните одну из команд в терминале (требуется установленный в системе [Allure CLI](https://framework.help)):

* **Вариант А: Локальный просмотр (Рекомендуемый)**
  Команда соберёт данные, поднимет локальный сервер и автоматически откроет отчёт в браузере:
  ```bash
  allure serve allure-results
  ```

* **Вариант Б: Компиляция в статичный HTML**
  Сборка отчёта в самостоятельную папку `allure-report` для передачи коллегам:
  ```bash
  allure generate allure-results -o allure-report --clean
  ```

## 💡 Особенности реализации тестов
* **Оптимизация скорости (API + UI):** Сквозные сценарии проверки Личного кабинета и Ленты заказов не тратят время на UI-клики сборки бургера. Тестовые заказы создаются в фоне через асинхронные API-запросы, а UI проверяет исключительно целевую страницу.
* **Пуленепробиваемые тесты счётчиков:** Счётчики «Выполнено за всё время/сегодня» проверяются на логическое увеличение (`>`), а не на строгий шаг `+1`. Это исключает падения тестов из-за параллельных действий других пользователей на стенде.
* **Защита от оверлеев:** Клики по ингредиентам и кнопкам защищены от перехвата слоями загрузки (анимации React) с помощью динамических JavaScript-кликов и умных ожиданий `WebDriverWait`.
